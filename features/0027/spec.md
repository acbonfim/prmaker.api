Cada bug é uma situação diferente: tem card que precisa de código (PRs), card que é só chamado para ajustar banco/Cognito, card que é só orientar o cliente, configuração direto no sistema etc. A analisar-bug precisa sugerir as etapas de correção de forma dinâmica, individuais para cada análise, a partir dos padrões de solução observados nas resoluções e timelines dos últimos cards.
