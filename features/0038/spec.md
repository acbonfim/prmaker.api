Melhoria na Base Solvace:

1. A tela é muito boa para ser lida por uma LLM, porém ela ainda é confusa para um usuário final olhar.
2. Gostaria que tivesse também textos e seções mais amigáveis para o usuário mais leigo, como QA, gestores, e um detalhamento em texto para o usuário.
3. Essas informações não precisam ir para a análise de uma LLM, já que ficaria muita informação para ela ler e o esquema por seção já funciona bem; só vai pra lá o que for necessário e performático para a análise dos bugs. Mas esses textos e seções para o usuário mais leigo devem existir.
4. Deve manter retrocompatibilidade — é apenas uma melhoria visual e para um usuário mais leigo poder consultar regras de negócio, entender o que cada módulo faz, como funciona uma integração, como se comunica com uma lambda, como um serviço é disparado, o que fica escutando e essas coisas.
