# Feature 0084 — Tour guiado da Base Solvace

Pedido do usuário (2026-11-04):

> Quero que construa, usando a ferramenta de tour, um passo a passo para usar a Base Solvace. Assim que o usuário entrar
> na tela, deve montar um tour com tudo que o usuário pode fazer, como realizar a configuração inicial, o que ele pode
> fazer e tudo mais.

- Reaproveitar o tour da 0081 (driver.js, `components/guided-tour/`).
- Abrir sozinho na primeira entrada na tela (por usuário/navegador); depois, pela ajuda ("Como usar esta tela").
- Cobrir a configuração inicial (IA pessoal, menu do usuário, modo de leitura), tudo o que qualquer pessoa pode fazer
  (Pergunte, filtro, lista, Knowledge Center, catálogo, mapa, um sistema por dentro, link, Aprender com um card) e o que
  só o administrador faz (sugestões, perguntas, ferramentas da seção, engenharia reversa).
