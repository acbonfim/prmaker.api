# 0104 — Rascunhos de histórias pelos cards do épico

Pedido do usuário (2026-11-27), a partir do card 79047: o Especialista do caso não conseguiu criar uma história dentro do
épico E1093 (o 79047 está no épico como vínculo) — o PRMake recusou com "O Especialista do caso só mexe nas histórias do
épico do caso dele".

Quero uma flag no épico, escolhida ao criar, que permita criar **rascunhos de histórias** dentro desse épico:

1. Pelo card só se cria **rascunho**.
2. O usuário/especialista dev **não converte em card**, a não ser que tenha acesso à Gestão com o papel específico
   (admin ou management).
3. A flag vem **habilitada por padrão** e o usuário pode alterar a qualquer momento.
